# Learnings

The inbox that keeps this repo's Claude setup improving. **Append-only**, committed, and
shared by the whole team. Written the moment something is learned, never "at the end":
a session that ends early would lose it.

`/ai-workflow:self-improve` turns `pending` entries into edits to rules, skills, agents or
hooks (or a proposed ai-workflow plugin change), then marks them `applied` or `rejected`.
A new session prints the pending count at start.

## Format

```
### YYYY-MM-DD — <one-line lesson>
- **Status:** pending | applied → <file> | rejected — <why>
- **Source:** user correction | reviewer finding | implementer note | retrospective | new pattern | tool/doc mismatch
- **Target:** <the rule/skill/agent/hook it should change, "ai-workflow plugin", or "new skill?">
- **Evidence:** <what happened, 1–3 lines; quote the user when it was their words>
```
